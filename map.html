Markdown 做的事可以一句話講完：用純文字的語法，寫出結構化的文件。下面從「核心語法」到「實作精通」拆解。

1. 核心語法 · Core Syntax

最常用的十種語法，佔日常寫作 90%（單元 2–5）。

標題# 到 ######，六級強調**粗體** *斜體*清單有序/無序/巢狀連結[文字](網址)
圖片![alt](url)程式碼行內/區塊/高亮引用> 引言區塊表格| 欄位 | 對齊 |

2. 進階擴展 · GitHub Flavored Markdown

GitHub 在標準 Markdown 上擴充的實用語法（單元 6）。

任務清單- [ ] / - [x]刪除線~~刪除~~自動連結URL/#issue/@mention註腳/emoji[^1] / :tada:

3. 生態系 · Ecosystem

Markdown 被哪裡使用：GitHub、靜態網站、筆記軟體（單元 7）。

GitHubREADME/Issue/PR靜態網站Hugo/Astro/mkdocs筆記軟體Obsidian/Logseq圖表Mermaid

4. 實作精通 · Practice

寫一份真正的 README，建立最佳實踐（單元 8）。

README完整實作常見錯誤檢查清單工具鏈markdownlint/pandoc

箭頭方向即學習順序：先核心語法，再 GFM，最後進入生態系與實作。

小結：Markdown = 「極少的語法」×「一致的渲染規則」。學會核心語法就能寫出 90% 的文件。
