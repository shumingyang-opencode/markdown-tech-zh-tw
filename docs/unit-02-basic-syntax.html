標題 · Headings

用 # 到 ###### 表示六級標題。# 越多，層級越低。建議 # 後面加一個空格。

原始碼 · SOURCE
# 標題一
## 標題二
### 標題三
渲染結果 · RENDERED

標題一

標題二

標題三

另一個寫法：在標題文字下一行放 ===（一級）或 ---（二級），但底線式寫法不常用。

強調 · Bold & Italic

原始碼 · SOURCE
**粗體**（雙星號）
*斜體*（單星號）
___粗體___ 也可用底線
渲染結果 · RENDERED

粗體（雙星號）

斜體（單星號）

粗體 也可用底線

建議：粗體用 **、斜體用 * 就好。 底線（_）在中文句子裡容易和文字黏在一起造成誤判，星號最直覺。

段落與換行 · Paragraphs & Line Breaks

段落之間用一個空行分隔；要在段落內強制換行，在行尾加兩個空格再 Enter。

原始碼 · SOURCE
第一段。

第二段（前面有空行）。

同一段內換行（行尾兩個空格）  
下一行還是同一段。
渲染結果 · RENDERED

第一段。

第二段（前面有空行）。

同一段內換行（行尾兩個空格）
下一行還是同一段。

常見錯誤：只按一次 Enter 在 Markdown 裡不會換行（會被合併成同一段）。 要開始新段落，請留一個空行。

無序清單 · Unordered Lists

用 -、*、+ 開頭。縮排四格（或兩格）可做巢狀清單。

原始碼 · SOURCE
- 蘋果
- 香蕉
  - 芭蕉（縮排巢狀）
    - 再下一層
- 奇異果
渲染結果 · RENDERED
  • 蘋果
  • 香蕉
    • 芭蕉（縮排巢狀）
      • 再下一層
  • 奇異果

有序清單 · Ordered Lists

用 1.、2. 開頭。一個貼心設計：數字寫什麼都可以，渲染時會自動重新編號——全寫 1. 也能得到 1, 2, 3。

原始碼 · SOURCE
1. 先安裝
2. 再設定
   1. 子步驟 A（縮排）
   2. 子步驟 B
3. 最後執行
渲染結果 · RENDERED
  1. 先安裝
  2. 再設定
    1. 子步驟 A（縮排）
    2. 子步驟 B
  3. 最後執行
實用技巧：在 - 或 1. 後面加空格再寫文字， 標記符號與內容之間的空格是語法的一部分。

動手練習

在 Dillinger 或 VS Code 開一個 practice.md，試著寫：

練習題 · PRACTICE
# 我的第一篇 Markdown

這是**重點**，這是*斜體*。

## 待辦清單

- 完成單元 2
1. 練習五種語法
2. 練習巢狀清單
看完這頁你應該能說出：
  • 六級標題的寫法，以及 # 後要加空格。
  • 粗體 **、斜體 * 的寫法。
  • 段落之間要空一行；段內換行要用行尾兩個空格。
  • 有序清單的編號會自動產生，數字寫錯也沒關係。
