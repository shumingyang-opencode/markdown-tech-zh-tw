2.1 標題 · Headings

用 # 到 ###### 表示六級標題。# 越多層級越低，建議 # 後加一個空格（GFM 強制）。

原始碼 · SOURCE
# 標題一
## 標題二
### 標題三
#### 標題四
##### 標題五
###### 標題六
渲染結果 · RENDERED

標題一

標題二

標題三

標題四

標題五

標題六

為什麼標題重要：標題是文件結構的骨架——多數渲染器自動產生目錄（TOC），且標題可被錨點連結（#標題）。一份文件應只有一個 H1。

2.2 強調 · Bold & Italic

原始碼 · SOURCE
**粗體**（雙星號）
*斜體*（單星號）
***粗斜體***（三星號）
~~刪除線~~（GFM）
__底線粗體__（可選）
渲染結果 · RENDERED

粗體（雙星號）
斜體（單星號）
粗斜體（三星號）
刪除線（GFM）
底線粗體（可選）

建議：粗體用 **、斜體用 *。底線 _ 在中文容易黏字、且與連結底線混淆，星號最直覺。巢狀強調如 **粗體內 *斜體*** 也合法。

2.3 段落與換行

段落之間用一個空行分隔；要在段落內強制換行，在行尾加兩個空格再 Enter。

原始碼 · SOURCE
第一段。

第二段（前面有空行）。

同一段內換行（行尾兩個空格）  
下一行還是同一段。
渲染結果 · RENDERED

第一段。

第二段（前面有空行）。

同一段內換行（行尾兩個空格）
下一行還是同一段。

最常見錯誤：只按一次 Enter 在 Markdown 不會換行（會被合併成同一段）。要開始新段落請留空行；行尾兩個空格對初學者易漏，建議多用空行。

2.4 無序清單 · Unordered Lists

用 -、*、+ 開頭。縮排四格（或兩格，但全站要一致）可做巢狀清單。

原始碼 · SOURCE
- 蘋果
- 香蕉
  - 芭蕉（縮排巢狀）
    - 再下一層
- 奇異果

* 用星號也可以
+ 用加號也可以
渲染結果 · RENDERED
  • 蘋果
  • 香蕉
    • 芭蕉（縮排巢狀）
      • 再下一層
  • 奇異果

（星號/加號渲染結果相同）

2.5 有序清單 · Ordered Lists

原始碼 · SOURCE
1. 先安裝
2. 再設定
   1. 子步驟 A（縮排）
   2. 子步驟 B
3. 最後執行
渲染結果 · RENDERED
  1. 先安裝
  2. 再設定
    1. 子步驟 A（縮排）
    2. 子步驟 B
  3. 最後執行
貼心設計：有序清單數字寫什麼都行，渲染時自動重新編號——全寫 1. 也能得到 1,2,3。但強烈建議寫正確數字：方便你「在原始檔直接看出順序」。
混用陷阱：在無序清單內夾有序清單、或反之，縮排要對齊到項目文字而不是標記符號，否則會跑版。

2.6 分隔線 · Horizontal Rule

原始碼 · SOURCE
上面一段

---

下面一段

***

2.7 Worked Example：今日待辦

原始碼 · SOURCE
# 今日待辦

**優先事項：**
1. 完成單元 2
2. 練習清單

**其他：**
- 買菜
  - 青菜
  - 雞蛋

---

明天再想。**重點是** 先動手寫。
渲染結果 · RENDERED

優先事項：

  1. 完成單元 2
  2. 練習清單

其他：

  • 買菜
    • 青菜
    • 雞蛋

明天再想。重點是 先動手寫。

練習：把「今日待辦」改用 * 無序清單 + 巢狀 + 一段引用，觀察渲染差異。

看完這單元你應該能說出：
  • 寫出六級標題並說出 # 後要加空格。
  • 區分粗體 **、斜體 *、刪除線 ~~，並寫出巢狀強調。
  • 說明段落與段內換行的規則（空行 vs 行尾兩空格）。
  • 寫出有序/無序/巢狀清單，並說明有序清單自動編號的特性。
