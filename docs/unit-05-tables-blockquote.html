5.1 表格 · Tables

表格用 | 分隔欄位，第二行用 --- 標示表頭，並可設定對齊：

原始碼 · SOURCE
| 名稱 | 預設 | 說明 |
|:-----|:----:|-----:|
| host | localhost | 主機 |
| port | 8080 | 連接埠（置中） |
| log  | auto | 日誌（靠右） |
渲染結果 · RENDERED
名稱預設說明
hostlocalhost主機
port8080連接埠（置中）
logauto日誌（靠右）

對齊語法：:--- 靠左、:---: 置中、---: 靠右。

表格內的特殊字元：管道符 | 需寫成 \|；程式碼用 ` 包住；換行可用 <br>。表格是 GFM 語法（標準 Markdown 不支援）。

5.2 引用區塊 · Blockquotes

用 > 開頭；巢狀引用用多個 >>；區塊內可放清單、段落與程式碼：

原始碼 · SOURCE
> 這是引用。
>
> - 引用內清單
>
> > 巢狀引用
>
> ```js
> const x = 1;
> ```
渲染結果 · RENDERED
這是引用。
  • 引用內清單
巢狀引用
const x = 1;
引用內換行：每一行都要以 > 開頭；空行也要 >（否則引用結束）。

5.3 分隔線 · Horizontal Rule

三個以上的 ---、*** 或 ___（中間可留空格）：

原始碼 · SOURCE
上面一段

---

下面一段
渲染結果 · RENDERED

上面一段

下面一段

避免誤判：--- 若緊跟在文字下一行（無空行），會被當成「二級標題」而非分隔線。要當分隔線時，前面務必留空行。

5.4 內嵌 HTML

需要進階排版（顏色、摺疊、影片、表格欄合併）時，直接寫 HTML——GFM 允許：

原始碼 · SOURCE
<details>
  <summary>點我展開</summary>
  摺疊內容
</details>

<p style="color: var(--fuchsia)">彩色文字</p>
渲染結果 · RENDERED
點我展開摺疊內容

彩色文字

安全注意：GitHub 會過濾危險 HTML（script、onload 等）。可用的多為展示性標籤（details、table、img、a）。

5.5 Worked Example：設定文件

原始碼 · SOURCE
# 設定說明

| 鍵 | 值 | 說明 |
|---|----|------|
| server.port | 8080 | HTTP 埠 |
| server.tls | true | 啟用 TLS |

> 修改後請重啟服務。

---
