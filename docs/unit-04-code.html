4.1 行內程式碼 · Inline Code

用反引號 ` 包住一段文字，變成行內程式碼——適合提及變數、指令、檔名：

原始碼 · SOURCE
執行 npm install 安裝依賴。

變數 score 是數字，設定檔在 config.yaml。
渲染結果 · RENDERED

執行 npm install 安裝依賴。
變數 score 是數字，設定檔在 config.yaml。

行內 code 的陷阱：行內 code 內的反引號需用雙反引號包住（`` `字面反引號` ``）；特殊字元（如 <）不會自動轉義，必要時手動寫實體。

4.2 程式碼區塊 · Code Blocks（圍欄式）

用三個反引號開頭與結尾，第二行指定語言可啟動語法高亮：

原始碼 · SOURCE
```python
def greet(name):
    return f"Hello, {name}!"
```
渲染結果 · RENDERED
def greet(name):
    return f"Hello, {name}!"
語言標記範例語言
常見python、javascript、typescript、go、rust
資料json、yaml、xml、sql
作業bash、sh、powershell、dockerfile
網頁html、css、markdown
GFM 進階：在區塊後可加「註解行」高亮（```python hl_lines="1 3"，部分平台支援）。

4.3 圍欄區塊內顯示反引號

程式碼本身包含三個反引號（如寫 Markdown 教學）時，用更多個反引號當圍欄：

原始碼 · SOURCE
````
```
這是內部的程式碼區塊
```
````
渲染結果 · RENDERED
```
這是內部的程式碼區塊
```

4.4 縮排式程式碼區塊（傳統寫法）

每行縮排四個空格或一個 tab，也是一種區塊寫法（GFM 仍支援，但不建議新文件使用，因無法指定語言高亮）：

原始碼 · SOURCE
    echo "這是縮排式區塊"
    exit 0
渲染結果 · RENDERED
echo "這是縮排式區塊"
exit 0
選擇：新文件一律用圍欄式（```）——可指定語言、可巢狀、不會被誤判。縮排式僅在極舊文件可見。

4.5 HTML 特殊字元安全顯示

在程式碼區塊內，<、>、& 不會被當成 HTML——直接原樣顯示（區塊是「免轉義」區域）：

原始碼 · SOURCE
```html

A & B < 10

```
渲染結果 · RENDERED
<div class="card">A &amp; B &lt; 10</div>

4.6 Worked Example：README 的安裝與使用

原始碼 · SOURCE
## 安裝

```bash
npm install my-tool
```

## 使用

```js
import { run } from 'my-tool';
run('config.yaml');
```
渲染結果 · RENDERED

安裝

npm install my-tool

使用

import { run } from 'my-tool';
run('config.yaml');

練習：寫一個「安裝 + 執行」的 bash 區塊，並加上 # 安裝、# 執行 註解。

看完這單元你應該能說出：
  • 用反引號寫行內 code，用三個反引號寫程式碼區塊。
  • 為程式碼區塊指定語言以取得語法高亮，並列出常見語言標記。
  • 在程式碼區塊內安全顯示反引號與 HTML 特殊字元。
  • 用 tab 縮排式區塊寫入純文字範例。
