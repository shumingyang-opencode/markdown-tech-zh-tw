學會語法只是開始。這一單元帶你認識 Markdown 在哪裡「被吃掉」—— 以及怎麼把一份 Markdown 變成網站、筆記與圖表。

GitHub：協作的樞紐

你在 GitHub 上寫的每一處都是 GFM：

位置用 Markdown 做什麼
README.md專案首頁：簡介、安裝、使用、徽章、截圖
Issue回報 bug、討論功能；模板常用任務清單
Pull Request描述變更、引用 issue（Closes #12）
Wiki專案文件集
討論區Discussion 貼文
連動語法：在 PR 描述寫 Closes #12，merge 時 GitHub 自動關閉 issue 12—— 這不是純排版語法，而是「語法連結工作流程」。

靜態網站生成器 · Static Site Generators

寫 Markdown，工具幫你產生 HTML 網站——這是部落格與文件網站的常見模式。

工具特點
HugoGo 寫的，極快；主題多
Astro前端導向，內容框架靈活
mkdocsPython 生態，最適合技術文件
VitePressVue 生態的文件站
GitHub Pages + Jekyllrepo 內放 Markdown，GitHub 自動生成
mkdocs 範例：內容檔 · CONTENT
# docs/index.md
# 我的文件

歡迎來到文件站。

筆記軟體 · Note-taking

現代知識管理工具以 Markdown 為底層，你的筆記就是純文字檔，可搜尋、可備份、永續：

  • Obsidian：資料夾即 vault，支援雙向連結、Mermaid、Canvas。
  • Logseq：outliner 式大綱筆記。
  • Notion：底層也是 Markdown 概念，可匯入匯出 Markdown。
Obsidian 特色：[[筆記名稱]] 是它的 wikilink——點一下跳到另一則筆記， 讓你的筆記庫長成知識網。

Mermaid：在 Markdown 裡畫圖

在 fenced code block 標上 mermaid，就能用文字畫流程圖、時序圖、甘特圖。GitHub 與 Obsidian 都支援。

原始碼 · SOURCE
```mermaid
graph LR
  A[寫 Markdown] --> B[渲染]
  B --> C[文件]
  B --> D[網站]
  B --> E[圖表]
```

示意：上面這份文字在 GitHub 上會被畫成一張流程圖（A 指向 B，B 分到 C/D/E）。

轉換工具 · Converters

Markdown 是「中間格式」，幾乎可以轉成任何東西：

  • pandoc：Markdown ↔ HTML / PDF / docx / epub，一站轉檔之王。
  • markitdown：微軟開源，把各種檔案（PDF、Office、網頁）轉成 Markdown。
  • Typora / VS Code：寫作時即時預覽。

AI 工具與 Markdown

生成式 AI 輸出的「文件」幾乎都是 Markdown：

  • 聊天機器人回覆常用 # 標題、- 清單、``` 程式碼。
  • 用 Markdown 寫 prompt 結構，AI 更易理解。
  • 會讀 Markdown = 能看懂 AI 給你的大綱、表格與程式碼。

  • Mermaid 如何用文字畫圖。
