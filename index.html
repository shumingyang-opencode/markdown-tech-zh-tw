為什麼學 Markdown？

現代開發者的日常處處是 Markdown：GitHub 上的 README、Issue、PR 描述， 筆記軟體（Obsidian、Notion）的底層格式，靜態網站（Hugo、Astro）的文章原始檔， 甚至你現在正看著的這份教學網站也是手寫 HTML 排版、內容用 Markdown 思維組織的。

學會 Markdown 等於拿到一把「結構化寫作」的鑰匙：語法不到十種、寫出的原始檔可讀、 隨處可渲染、且永遠不會過時。本課程用 中英對照 的方式，帶你一次掌握它。

立即體驗：原始碼 vs 渲染結果

Markdown 的輸入是純文字，輸出是格式化文件。下面這幾行就是「原始碼 → 渲染」的實況：

原始碼 · MARKDOWN SOURCE
# 標題一
**重點** 與 *斜體*

1. 第一項
2. 第二項

`行內程式碼`
渲染結果 · RENDERED

標題一

重點 與 斜體

  1. 第一項
  2. 第二項

行內程式碼
