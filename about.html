這個網站是什麼

一份把 Markdown 從核心語法、GitHub Flavored Markdown，到整個生態系（GitHub、靜態網站、Obsidian、Mermaid）做成中英對照的深度教學的繁體中文網站。每個單元都附可照做的 Worked Example 與練習。

為什麼要學 Markdown

  • 語法極少，學會核心就能寫出 90% 的文件。
  • 原始檔可讀、可版本控制、永遠不過時。
  • GitHub、筆記軟體、靜態網站、AI 工具全都擁抱它。

本站建置

  • 規劃 8 單元深度課程（認識 → 基礎 → 結構 → GFM → 生態 → 實作）
  • 承襲既有教學站的深色 × 霓虹設計語言與架構慣例
  • 每個單元設計「定義/原理 + 步驟 + Worked Example + 練習 + 看完應能說出」結構
  • 新增術語表速查頁

授權

本站教學內容（繁體中文解說）為本站原創，以 CC-BY-4.0 授權釋出。英文術語與語法示範引用自 Markdown 官方規格與 GitHub Flavored Markdown 規格。
